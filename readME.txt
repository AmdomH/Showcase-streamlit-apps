# 🌟 Showcase Streamlit Apps: Data Missingness Analysis

![Python](https://img.shields.io/badge/Python-3.8%2B-blue) ![Streamlit](https://img.shields.io/badge/Streamlit-1.0%2B-red) ![License](https://img.shields.io/badge/License-MIT-green) ![Status](https://img.shields.io/badge/Status-Active-brightgreen)

Welcome to **Showcase Streamlit Apps**! 🚀 This repository hosts an interactive web application built with Streamlit to analyze and treat missing data in the Air Quality dataset. Whether you're a data scientist, researcher, or enthusiast, this app provides powerful tools to explore data missingness, visualize distributions, and compare imputation methods. Let’s dive in! 📊

---

## 🎯 Features

- **Interactive Data Exploration** 🧐
  - Filter data by month using a sleek sidebar.
  - Visualize Ozone distribution, joint distributions, correlation heatmaps, and more with Matplotlib and Seaborn.

- **Missing Data Analysis** 🔍
  - Inspect missing values with a detailed summary table.
  - Download missing data summaries as CSV for further analysis.

- **Imputation Methods** 🛠️
  - Choose from multiple imputation techniques: Complete Case Analysis (CCA), KNN, MICE, and more.
  - Compare regression results (slope, standard error) across methods in a summary table.

- **Advanced Visualizations** 📈
  - Correlation heatmaps to understand variable relationships.
  - Boxplots to explore Ozone levels by month.
  - Residual plots to diagnose regression models.

- **Portfolio Page** 🌟
  - Learn about the author (Amdom) with a professional bio and photo.
  - Connect via LinkedIn and GitHub links.

- **Modern Styling** 🎨
  - Gradient background (dark blue to light blue).
  - Gold headers, orange buttons with hover effects, and a teal sidebar for a polished look.
